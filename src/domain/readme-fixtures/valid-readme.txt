Lightweight and responsive form builder for WordPress with anti-spam protection.

== Description ==

WP Form Pulse is a high-performance form builder designed for modern WordPress websites. Build beautiful forms in seconds with live preview and no bloat.

=== Core Features ===

* Drag-and-drop form editor
* Built-in honeypot and turnstile spam protection
* Webhook integrations and REST API endpoints
* Zero external asset dependencies on front end

== Installation ==

1. Upload `wp-form-pulse` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to Form Pulse in the admin sidebar to create your first form.

== Frequently Asked Questions ==

= Does it work with block themes? =

Yes, WP Form Pulse includes full block theme and Gutenberg support.

= Can I export submissions to CSV? =

Yes, submission export is available directly from the entries management screen.
